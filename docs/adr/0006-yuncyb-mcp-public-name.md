# ADR 0006：MCP 对外名称统一为 yuncyb

- 状态：已被 ADR 0007 扩展；对外名称决策仍然有效
- 日期：2026-09-23
- 替代：ADR 0001、ADR 0002 中的 `erp-billing` 服务命名决策

## 背景

管家婆是企业品牌，云创业版是具体产品。服务已经覆盖销售、采购、库存、资金往来
与经营报表，`erp-billing` 容易突出底层系统和单一开单能力，不能准确表达产品身份。

行业官方 MCP 通常直接使用产品名称作为服务名。云创业版现有域名也使用
`yuncyb.com`，因此采用相同的简短产品标识。

## 决策

1. MCP initialize 的 `name` 统一为 `yuncyb`。
2. WorkBuddy 两种连接配置中的 `mcpServers` 键统一为 `yuncyb`，连接器与 Skill 的
   展示名称统一为“管家婆云创业版”。
3. OAuth 保护资源展示名和直连认证 realm 同步使用新名称。
4. 工具名称、HTTP 地址、鉴权方式和业务契约不变。
5. 本 ADR 仅决定对外名称；内部技术标识的完整重命名由 ADR 0007 处理。

## 结果

- 客户端重新连接后看到的产品名称为 `yuncyb`，不再将服务误解为单一开单模块。
- 本决策首次落地时可沿用旧部署槽位；ADR 0007 后需执行一次完整迁移。
- 后续新增业务工具无需再次调整 MCP 服务名。
